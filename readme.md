# 📊 Dashboard de Indicadores de Saúde em Adolescentes

Este projeto é uma aplicação web que apresenta um **Dashboard de Indicadores de Saúde em Adolescentes**. Ele foi desenvolvido de forma colaborativa para transformar uma ferramenta de visualização de dados em uma aplicação web nativa e customizada.

## 🤝 Contexto e Colaboração

Este repositório é fruto de um trabalho colaborativo:

* **O Projeto Original (PIBITI):** O dashboard nasceu como resultado do trabalho de **Ellen Gabriela Alves Soares** (vinculada ao Grupo de Pesquisa em Atividade Física e Desenvolvimento Humano - GPAF) para o Programa Institucional de Bolsas de Iniciação em Desenvolvimento Tecnológico e Inovação (PIBITI). Originalmente, a ferramenta foi prototipada e desenvolvida utilizando o Google Data Studio (Looker Studio).
* **A Migração para Código:** Para garantir maior flexibilidade, performance e controle sobre a interface, eu assumi a tarefa de reescrever e traduzir todo o dashboard desenvolvido no Data Studio para código puro, estruturando a aplicação em tecnologias web padrão.

## 🛠️ Tecnologias Utilizadas

A versão atual hospedada neste repositório foi construída utilizando:

* **HTML5:** Para a estruturação semântica do dashboard.
* **JavaScript:** Para a lógica de manipulação dos dados, interatividade e renderização dos gráficos.
